# Level 2 — Tribute Page: A. P. J. Abdul Kalam

An original, responsive tribute to scientist and former President of India A. P. J. Abdul Kalam. The biography is paraphrased, and the portrait attribution and source links are included below and on the page.

## Features

- Biography, milestones, a quote, and source notes
- Responsive editorial layout with two contrasting sections
- Serif display headings and sans-serif body type
- Image provided by the President's Secretariat, India

## Image attribution

Portrait: **President's Secretariat, India**, via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:A.P.J_Abdul_Kalam.png), licensed under the [Government Open Data License – India (GODL-India)](https://data.gov.in/sites/default/files/Gazette_Notification_OGDL.pdf). The source page requires attribution.

## Run

Open `index.html` in a browser. The portrait and Google Fonts load from their source websites, so those assets require an internet connection.
