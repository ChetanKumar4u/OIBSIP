## Run the projects

- **Browser demos:** [Open the GitHub Pages project hub](https://chetankumar4u.github.io/OIBSIP/). It runs the six static projects. The Level 2 login app and Level 3 pizza app need a separately hosted Node.js backend; the pizza app also needs MongoDB.
- For the static projects, open the folder's `index.html` in a browser. The to-do app saves data in that browser's local storage.
- For the login project, follow the PowerShell setup in [`WebDev-L2-LoginAuthenticationSystem/README.md`](WebDev-L2-LoginAuthenticationSystem/README.md); it requires Node.js and an ephemeral `SESSION_SECRET`.
- For the Level 3 pizza app, follow [`WebDev-L3-PizzaDelivery/README.md`](WebDev-L3-PizzaDelivery/README.md); it requires Node.js and MongoDB.

Every project folder has a README with its features and run steps. Before submitting:

1. Run each project and prepare a short, end-to-end demonstration.
2. Begin each video with a two-second title card showing your full name, assigned track, and task title.
3. Name each submission using the required `YourName_TaskNumber` format.
4. Share the milestones/demo on LinkedIn, tag Oasis Infobyte, and include `#oasisinfobyte`.
5. Complete any cohort peer-evaluation requirement in the assessment document.
6. Submit through the official form with this GitHub repository link and a live demo link if you publish one.

The static projects run locally in a browser. The authentication project requires Node.js and a local Express server; it is an educational demo, not a production login service.
