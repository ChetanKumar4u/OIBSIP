# Level 2 — To-Do Web App

A small, responsive daily planner with separate pending and completed lists. Tasks are stored in the browser using `localStorage`.

## Features

- Add, edit inline, complete/uncomplete, and delete tasks
- Pending and completed counts update immediately
- Creation and completion timestamps
- Friendly empty states and clear validation
- State persists after a page refresh

## Run

Open `index.html` in a browser. Use the input to add a task, then use the task controls to edit, complete, or remove it. Refresh the page to confirm persistence.

## Data note

Tasks remain in the current browser profile on this device. Clearing site data removes them; this project does not sync tasks across devices.
